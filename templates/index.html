The mask warns; it does not remove. Every sector is currently soft, so a target in poor sky stays in the queue carrying a badge. The north is avoided because Trieste sits 41 km away at bearing 3° and lights that sky, not because anything obstructs it — and an impactor found in the north has to appear on this board. Mark a sector hard in site.horizon_mask only once it is confirmed as a physical obstruction. The observatory's own planner has no azimuth mask at all, only a flat altitude floor.

Azimuths are compass bearings from north. MPC reports azimuth from south; it is converted on parse and verified against an independent astropy calculation every cycle. That convention was confirmed against 579 ephemeris lines of the observatory's own output — read as compass, five of 579 targets fall in the north; read raw, north would be the busiest sector on the sky.

Shoot is {{ site.exposure_frames }} frames for every target, with the frame length set by how fast the object is moving at its best altitude — the observatory's own table: {% for limit, secs in site.exposure_speed_bands %}≤{{ limit|int }}″/min → {{ secs }}s{{ ', ' if not loop.last }}{% endfor %}, faster → {{ site.exposure_fastest_sec }}s.

The plan file also still carries obsExposure, the legacy figure from planets-new.py: total integration in minutes from magnitude alone, {{ site.exposure_base_min|int }} + (V − {{ site.exposure_ref_mag|int }}) × {{ site.exposure_min_per_mag|int }}, floored at {{ site.exposure_floor_min|int }} (unfloored it goes negative for bright targets, and the observatory's own files contain obsExposure=-2.0min). It ignores sky motion entirely, so it will not agree with Shoot — a slow target is {{ site.exposure_frames }}×{{ site.exposure_speed_bands[0][1] }}s = {{ (site.exposure_frames * site.exposure_speed_bands[0][1] / 60)|int }} minutes on sky against an obsExposure nearer 27. Shoot is the instruction.

Still open: which sectors, if any, are real obstructions rather than preferences. Also SW, never specified and interpolated to 30°; NW, given as both 50° and 40°; W, as both “30–40” and 40°; and an upper elevation limit mentioned but never valued.

Ordered by when each target reaches its best observable altitude, so working down the list keeps every target near its peak — the same sequencing the observatory's own planner uses. Value is a separate intrinsic score from digest2, arc length and magnitude; it excludes altitude on purpose so it stays meaningful in daylight, and it does not drive this order.

Positions come from MPC ephemerides generated for L01 and are recomputed independently with astropy each cycle, so a disagreement is flagged rather than hidden. The pointing line is interpolated {{ site.interpolate_ahead_s // 60 }} minutes ahead to allow for slewing.

Clock times on this page are {{ tzname }}, local to the observatory; hover any of them for UT. The plan file and the ephemeris lines inside it stay in UT, because that is what MPC and the 80-column astrometry format require — changing them would break the format.
